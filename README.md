# Hanol · 수업 횟수 관리

이 아카데미는 **월 납부를 사용하지 않습니다.** 학생은 수업 횟수 패키지를 구매합니다.

## 규칙

- 기본 수업 패키지: **4회**
- 출석 1회 = 수업 1회 자동 소모
- 출석 4/4가 되면 **결제 필요** 상태 생성
- 대시보드에 **등록 안내** 자동 표시
- 학생 상세는 항상 `■■■□ 3 / 4` 형식의 진행률 표시
- 월별 등록금 계산 로직 없음 (전부 수업 횟수 기준)

## 실행

```bash
npm install
npm run dev
```

- 대시보드: `/`
- 학생 목록: `/students`
- 학생 상세: `/students/[id]`

## 검증

```bash
npm test
npm run lint
npm run build
```

로컬 데이터는 `.data/store.json`에 저장됩니다.
